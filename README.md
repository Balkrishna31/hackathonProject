# 📋 MyTask – Task Management Landing Page

**MyTask** is a frontend prototype of a task management website built using **HTML** and **CSS**. This project was created to practice modern web design concepts, responsive layouts, and UI development while learning frontend technologies.

> **Note:** This is a static frontend project. It does not include backend functionality, authentication, or database integration.

## ✨ Features

* Clean and modern landing page
* Responsive navigation bar
* Custom logo and branding
* Call-to-action button for Google Sign-In (UI only)
* Subscription plans section

  * Premium
  * Regular
  * Restricted
* Hover effects and button animations
* External Google Fonts integration
* Bootstrap icons and styling support

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap 4
* Google Fonts

## 🎯 Purpose

This project was built to practice:

* HTML page structuring
* CSS styling and layouts
* Flexbox
* Navigation bar design
* Buttons and hover effects
* Typography using Google Fonts
* Building a modern landing page UI
